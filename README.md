# React Native - zadania projektowe

Projekt Expo zawiera dwa ekrany wykonane w React Native:

- Zadanie 1: katalog wydarzen z wyszukiwaniem, filtrami kategorii, trybem ulubionych i kartami wydarzen.
- Zadanie 2: panel uzytkownika z formularzem, walidacja, ustawieniami, motywem jasny/ciemny, licznikiem bio i polem hasla.

## Uruchomienie

```bash
npm install
npm start
```

Projekt korzysta z Expo SDK 54, React Native, `StyleSheet.create()`, `Pressable`, `TextInput`, `ScrollView`, `FlatList`, `useState` i `useEffect`.
