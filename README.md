# React Native - zadania projektowe

Projekt Expo zawiera trzy ekrany wykonane w React Native:

- Zadanie 1: katalog wydarzen z wyszukiwaniem, filtrami kategorii, trybem ulubionych i kartami wydarzen.
- Zadanie 2: panel uzytkownika z formularzem, walidacja, ustawieniami, motywem jasny/ciemny, licznikiem bio i polem hasla.
- Zadanie 3: komunikacja REST API z GET /posts, POST /posts, lista FlatList, formularz, loading, error i odpowiedz serwera.

Autor: Wiktor Gałązka.

## Uruchomienie

```bash
npm install
npm start
```

Projekt korzysta z Expo SDK 54, React Native, `StyleSheet.create()`, `Pressable`, `TextInput`, `ScrollView`, `FlatList`, `fetch`, `useState` i `useEffect`.
